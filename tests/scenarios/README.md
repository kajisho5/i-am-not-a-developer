# Manual scenarios

Five prompts to check the skill by hand. Each file lists the setup, the prompt, and what a
passing reply looks like. The 10 rules in `skills/i-am-not-a-developer/SKILL.md` are the grading
sheet.

How to run one:

1. Install the plugin (see the main README).
2. Make the folder described in **Setup** and open Claude Code in it.
3. Paste the **Prompt**.
4. Compare the reply with **Pass if** and with the 10 rules.

Replies that passed are copied to `docs/examples/`.
