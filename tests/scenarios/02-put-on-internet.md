# 02 — "How do I put this on the internet?"

## Setup

Same folder as scenario 01 (small Vite site, not deployed, no git).

## Prompt

```
/i-am-not-a-developer how do I put this on the internet
```

## Pass if

- Picks one boring, well-known option with a free plan; no menu of five hosts.
- Stops before publishing or creating accounts: says what will be public, what it costs, how to undo, and asks for "yes".
- Names places to click (site name, button label) instead of "deploy it".
- No 8-step list; one action, then waits.
- Ends with exactly one next action.
